# UI kit — Aplicações

Click-through das peças da marca. Barra lateral troca a peça; os campos "Bar parceiro", data e horário alimentam todas as peças com co-branding. No cardápio, os nomes das bebidas são editáveis (slot vazio = tracejado).

- `Social.jsx` — ProfilePic, EventPost, Story, CollabPost
- `Print.jsx` — Flyer (A4), TableTent, Menu, MiniBoard
- `Merch.jsx` — Fichas, Stickers, TableCloth (pano de mesa planificado)

Todas as peças são renderizadas no tamanho real (px @96dpi para impressos) e escaladas para caber. Componentes vêm de `window.XA` (bundle do design system).

Peças criadas do zero a partir do briefing — não há arquivos originais da marca.
