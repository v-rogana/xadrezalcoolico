Linha do cardápio das peças (peça → bebida) com área modular para trocar o nome da bebida a cada evento.
```jsx
<MenuItem piece="dama" drink="Gin tônica" note="Gin, tônica, limão" count={1} side="rosa" />
<MenuItem piece="peao" count={8} />  {/* slot vazio tracejado */}
```
Ordem canônica: rei, dama, torre, bispo, cavalo, peão. `dark` para cardápio em fundo preto.
