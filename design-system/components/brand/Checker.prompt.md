Bloco de quadriculado de tabuleiro — use como faixa, borda ou fundo (recurso obrigatório da marca).
```jsx
<Checker palette="classic" cell={24} height={48} />
<Checker palette="duel" cell={40} width={320} height={320} />
```
Regra: texto nunca diretamente sobre o quadriculado — use uma área sólida (cartela) por cima.
