Etiqueta pílula para metadados curtos (data, bar, +18, notação de lance).
```jsx
<Tag tone="amarelo">Sex · 22h</Tag>
<Tag mono upper={false} tone="rosa" rotate={-4}>Dxf7#</Tag>
```
Tons: preto, rosa, amarelo, creme. `mono` troca para Courier Prime negrito caixa alta; `upper={false}` mantém a caixa original (obrigatório para notação de lance). `rotate` dá inclinação de adesivo.
