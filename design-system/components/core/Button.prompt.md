Botão principal da marca (pílula, borda preta 3px, sombra dura) — use para CTAs em telas, stories e peças digitais.
```jsx
<Button variant="rosa" size="lg">bora jogar</Button>
<Button variant="outline">ver cardápio</Button>
```
Variantes: primary (preto, sombra rosa), rosa, amarelo, outline. Tamanhos sm/md/lg. Texto em Darumadrop, caixa baixa ou de frase, curto (1–3 palavras).
